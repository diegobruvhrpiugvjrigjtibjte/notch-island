Questions

  

    
Does the agent need an API key or cost money?
No. It runs the claude command line that comes with Claude Code, using the account you are already logged in with, so it counts against your Claude plan — no API key, no per-token billing.

    
Is my voice sent anywhere?
No. Recognition runs locally with whisper.cpp. The program and model are downloaded once from GitHub / Hugging Face and verified.

    
Can it delete my files?
Destructive commands (rm -rf, del /s, format, shutdown…) are blocked and Claude is told to ask before anything irreversible. You can also set it to “Read only” or turn it off.

    
I have two monitors. Which one shows the pill?
Your choice: Settings → Appearance → Display lists every connected screen.

    
Why does Windows warn me about the installer?
It isn't code-signed yet. The source is public and the SHA-256 is published here so you can verify the file.

    
What about macOS and Linux?
Not yet — the system agents are PowerShell/WinRT. Contributions are welcome.
